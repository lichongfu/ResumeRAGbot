# v3 候選：職缺專屬作品導覽與面談準備單

版本：`3.0.0-candidate.4`。這是 lichongfu 的候選功能，不是老師的正式 v3。
相關討論：https://github.com/canlgz/ResumeRAGbot/discussions/1

## 主要流程

貼完整職缺 → AI 摘錄條件 → 人資確認或移除條件 → 逐項查找履歷證據 → 查看相關作品與面談準備單。

所有訪客均可使用，同一 LINE 帳號即可測試。主要流程不需要角色切換，也不要求 `OWNER_LINE_USER_ID`。
原本的通知與三題訪談保留於首頁「選配：本人三題訪談」中；操作方式見 [職缺補充訪談](職缺補充訪談.md)。

## LINE 操作

1. 輸入「首頁」，點第三張卡「貼職缺，看證據與作品」，或輸入「職缺證據導覽」。
2. 收到資料用途提示後，貼職稱、工作內容及條件，20～4000 字。只有職稱或網址時會提醒補充，不會把它保存成完整職缺。
3. 系統挑選最多六項重點，逐字摘錄原文。確認頁可移除個別條件或重新貼職缺；每次至少保留一項。六項不代表涵蓋全部職缺內容。
4. 點「確認條件，開始比對」。每次處理一項，未完成時點「繼續比對下一項」。最後一項完成後自動顯示面談準備單。
5. 點「查看相關作品」，查看與本次引用來源相關、本人已開放的作品預覽。沒有對應公開圖片時仍可看專案文字，不會自行公開原圖。
6. 準備單可直接長按複製，提供主管討論；也可輸入「面談準備單」重新開啟。這是 LINE 文字格式，尚未提供 PDF 或多人比較。

在條件確認前，直接再貼完整職缺就會取代原職缺，不需要先取消；開始比對後請點「重新貼職缺」。舊卡片不能操作新的職缺。
輸入「首頁」或點「離開」可暫停。重新開啟後輸入「取消」可刪除目前職缺與準備單；已傳出的 LINE 訊息無法收回。

測試職缺：

```text
職缺：AI工程師
工作內容：使用 Python 開發 AI 應用，串接 API。
必要條件：具備 Python 專案經驗。
加分條件：使用過 Google Apps Script。
```

## 如何解讀結果

- 每項條件列出原文引用、章節及片段 ID，以及正式面談可追問的問題。
- 結果稱為「相關履歷證據」，不自動斷言符合條件，不將向量相似度當成能力分數。
- 找不到可核對引用時標為待確認；未記載不代表不具備能力。
- 原文中的必要／加分類型由明確的行首標題判斷，不由模型任意指定。未辨識、跨行或相同文字出現不同類型時列為「未指定」，請人資核對。
- 模型挑選引用後，程式會核對引用 ID 必須出現在本次檢索結果，且引文逐字存在於同一片段。逐字核對不保證語意或真實性，仍需面談查證。
- 圖片只代表可見內容，不推定作者、本人貢獻、技術、正式上線或成果。
- 準備單明確標示尚未蒐集本人補充；不會把人資輸入當成應徵者回答。
- API 額度、格式不合或引用核對失敗會顯示錯誤及重試入口，不當成履歷資料不足。

## 資料與部署

職缺及少量檢索片段會送至 Gemini，每項使用一次查詢向量與至多一次生成請求。
不重建履歷索引、不重新 OCR、不把職缺寫回 Doc、待補充問題或履歷索引，不發送邀約、信件或推播。
每位訪客保存一份準備單，使用專案及 Doc 綁定的雜湊隔離，存於本人私人 Drive。最多三十位訪客；24 小時後禁止查閱，後續操作時清除，沒有背景清理排程。
慢請求使用租約，不能覆蓋重新貼上的職缺。快取不作為準備單的唯一保存方式。
開始分析、生成後與查看準備單／作品時都核對來源與索引 fingerprint；來源改變時停止顯示舊證據，需先同步後重新比對。
準備單版本跟隨履歷來源；公開圖片另檢查現有開放狀態。舊訊息與自行複製的內容不能撤回。

更新時完整貼入新 `dist/Code.gs`、核對 manifest、儲存，再編輯原 Web App 部署並選「建立新版本」，沿用原 `/exec` 網址。
執行 `checkDeployment`，編輯器與正式部署應同為 `3.0.0-candidate.4` 且 `status=ready`。Push 不會自動更新 GAS。

## 驗收狀態

本機測試涵蓋分檔與單檔完整流程、條件引用及類型、短職稱提醒、更換職缺、移除條件、分步與重送、來源變更、引用拒絕、API 錯誤、權限隔離、已開放作品篩選、取消、過期與慢請求。
沒有真實 API 或 LINE 量測結果，不宣稱招募時間或準確率改善。

| LINE 操作 | 預期結果 | 實際結果 |
| --- | --- | --- |
| 未設定本人通知也能貼完整職缺 | 出現條件確認，不要求切換角色 | 尚未實測 |
| 只貼 AI 工程師，再補完整內容 | 提醒補充後正常整理，不卡在選原文 | 尚未實測 |
| 確認條件、逐項比對 | 引用有來源，缺資料標為待確認 | 尚未實測 |
| 查看作品及複製準備單 | 只顯示相關已開放預覽，文字可複製 | 尚未實測 |
| 更改 Doc、尚未同步 | 不提供舊證據或圖片 | 尚未實測 |
| 首頁、履歷問答、邀約及選配訪談 | 原有操作正常 | 尚未實測 |
